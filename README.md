# PlanDestination

A full-stack travel booking platform: flights, hotels, homestays, holidays, trains, buses, cabs, cruises, activities, visas, insurance, forex and gift cards.

Payments go through PlanPay, its own gateway: cards, UPI, net banking, wallet, EMI and Pay Later, with 3-D Secure-style OTP and refunds.

Built with React 18 and Express 5.
